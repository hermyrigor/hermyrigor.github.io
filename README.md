# Hermy Rigor | Personal Portfolio

Portfolio website of **Hermy Rigor**, a BS Information Technology graduate from San Mateo, Isabela, open to web development, IT support, and IT staff roles.

**Live site:** https://hermyrigor.github.io

## About this project

A responsive, single-page portfolio built with plain HTML, CSS, Bootstrap, and vanilla JavaScript. There is no framework and no build step. It presents my background, skills, internship experience, capstone project, training in progress, and a working contact form.

## Features

- Responsive layout for phones, tablets, laptops, and desktops
- Dark and light themes that follow the visitor's device setting and remember their choice
- Hero text with a decode animation, switched off for visitors who prefer reduced motion
- Screenshot gallery with a keyboard-accessible viewer
- Contact form with client-side validation and a hidden spam-trap field, delivered by [Web3Forms](https://web3forms.com)
- Accessibility work: skip link, visible focus states, descriptive alt text, and correct heading order

## Run locally

No installation is needed.

1. Clone or download this repository.
2. Open the folder in VS Code.
3. Install the **Live Server** extension and click **Go Live**.

The contact form sends real messages when used on a live or local page.
